## 手工点击期间的记录

为避免短期缓存到期后漏查，在 Mac 上经现有 SSH 通道使用只读账号，每 15 秒观察一次 Redis 键与 TTL；仅在新键或新版本出现时读取正文。记录器在用户完成后已停止，没有安装常驻监控。

保存的记录涵盖 17:11:29—17:17:18：22 个版本记录，其中包含启动观察时已有的缓存，以及之后的新增缓存；不能把 22 条全部当作用户新生成的缓存。类别包括月球、火星、天气、天象和图片墙。地球总览、深空在更早的自动点击阶段完成了浏览器正文与 Redis 对照，本次手工观察窗口未捕获这两类的新版本。

部分 60 秒或 120 秒缓存在用户点完后已经自然过期，属于预期行为；归档中仍保留其内容、获取时间和当时 TTL。被检查的键都具有正数有效期，没有发现永不过期的响应缓存。不同地点出现多组参数键是正常隔离，不能单凭这些键证明界面所有地点切换都正确。
